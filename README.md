# simple-shop 在线购物系统

> 单卖家在线购物系统：买家注册登录后浏览在售商品，加入购物车或收藏，结算下单并支付，确认收货后可申请售后；卖家在后台维护商品与类别、确认备货发货、处理售后。系统不承载真实支付渠道与物流轨迹。

## 项目定位

- **商品**：卖家发布，库存独立管理；只有「在售」「已下架」两种状态，已下架分手动下架、库存耗尽、已售三类来源。
- **交易**：订单取代购买意向，一笔订单含多件商品，按「待支付 → 已支付 → 已确认 → 备货完成 → 已发货 → 交易完成」整单流转。
- **支付**：下单即待支付，24 小时未付自动取消；四个渠道（银行卡、信用卡、支付宝、微信）本期统一走 Mock；已支付订单取消即全额原路退款。
- **取消**：买家在发货前可取消，卖家在完成前可取消；取消不影响库存，已支付的取消会退款。
- **库存**：下单只校验、不预占，买家确认收货（成交）时才扣减；扣到 0 的商品自动下架，已下架商品成交不扣库存。
- **配送**：买家维护收货地址簿（上限 10、可设默认），下单写地址快照；卖家发货填承运商与物流单号，发货后仍可修改。
- **售后**：交易完成的订单可按订单项申请售后，卖家线下协商后登记结果（退货并退款 / 仅退款 / 换货），退款按整行金额自动写入；同一订单项只能退款一次。
- **订单状态**：七态（待支付 → 已支付 → 已确认 → 备货完成 → 已发货 → 交易完成 / 已取消），交易完成由**买家确认收货**推进，卖家没有「完成订单」入口。
