# simple-shop 在线购物系统

> 单卖家在线购物系统：买家注册登录后浏览在售商品，加入购物车或收藏，从购物车多件下单；卖家在后台确认、备货、发货并登记交易完成。系统不承载支付与物流。
>
> **当前阶段：阶段三进行中。** 本文件将在阶段三交付后统一更新。

## 项目定位

- **商品**：卖家发布，库存独立管理；只有「在售」「已下架」两种状态，已下架分手动下架、库存耗尽、已售三类来源。
- **交易**：订单取代购买意向，一笔订单含多件商品，按「待确认 → 已确认 → 备货完成 → 已发货 → 交易完成」整单流转。
- **取消**：买家在发货前可取消，卖家在完成前可取消；取消不影响库存。
- **库存**：下单只校验、不预占，交易完成时才扣减；完成后库存为 0 的商品自动下架。
