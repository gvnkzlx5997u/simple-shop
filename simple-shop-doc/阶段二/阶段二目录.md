## 阅读建议

1. 先读升级需求与澄清记录，了解业务口径。
2. 再读状态模型设计，确认商品与意向的状态、迁移和归档。
3. 最后读后端开发计划，按 S0～S6 推进重构。
4. 进入收口阶段前读后端架构改造设计，按 S1～S6 完成库存解耦与接口化。
5. 部署前先读安装与部署手册的「阶段二适用性」；默认测试需要 Docker，无 Docker 用本机 MySQL profile。
6. 收口记录见《阶段二剩余事项交接》：E2E 已执行、本地构建与云端 1.0 镜像已推送。性能测试可选，本阶段不做。
