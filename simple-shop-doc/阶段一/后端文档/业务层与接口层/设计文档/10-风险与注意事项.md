# 10. 风险与注意事项

| # | 风险 / 易错点 | 影响 | 对策 |
| --- | --- | --- | --- |
| **R1** | **`javax` vs `jakarta`**：Spring Boot 3.5 用 `jakarta.*` | 编译失败 | 全部用 `jakarta.persistence.*`、`jakarta.validation.*`、`jakarta.servlet.*` |
| **R2** | **`snake_case` 未映射**：Java 驼峰字段被直接序列化 | 前端拿不到字段（契约违背） | DTO 字段**逐个** `@JsonProperty("pic_url")`；Controller 测试断言 JSON 键名 |
| **R3** | **加锁顺序反了**：`markTradeFailure` 的「重排队」需要序号表行锁，若在商品行锁**之后**才取，与 `submitIntention`（先序号表）构成反向取锁 | **死锁** | **在取商品行锁之前**先判断 `disposal == requeued`，若是则**先取序号表行锁**。写成注释并加并发测试 |
| **R4** | **归档遗漏前置 `INV-05` 校验** | 历史表出现非终态意向（`INV-05` 违反，数据库**无兜底**） | `ArchiveService.archive` 的**第一步**就是 `countActiveByGoodsId > 0 → 抛 30005`；加集成测试断言 `countActive == 0` |
| **R5** | **给历史实体加 JPA 回调** | 归档时间被覆盖 | **绝不给** `GoodsHistory`/`IntentionHistory` 加 `@PrePersist`/`@PreUpdate`；归档时统一走 `EntityFactory` + 显式赋值 |
| **R6** | **`LocalDateTime.now()`** | 时间偏 8 小时，且 `validate` 查不出来 | 全项目只允许 `DatabaseTimeProvider`；可用一条 `grep` 检查（见下） |
| **R7** | **新增时间字段漏标 `@JdbcTypeCode(SqlTypes.LOCAL_DATE_TIME)`** | 静默偏 8 小时 | 本轮**不新增实体字段**；若确需新增（如会话实体，但本方案用内存态），必须一并标注 |
| **R8** | **误用 `Goods.setResult()`** | 违反 `DEC-DB-11`（当前表该列恒 NULL） | 代码评审检查项；`GoodsHistory` 才写 `result` |
| **R9** | **`osiv` 关掉后懒加载异常** | 运行时 `LazyInitializationException` | Service 返回 DTO；`Intention.getGoods()` 只在事务内用；**不要把实体带出事务** |
| **R10** | **`MultipartException` 未处理** | 超 5MB 变成 500 而非 `20009` | `GlobalExceptionHandler` 捕获 `MaxUploadSizeExceededException` |
| **R11** | **业务拒绝返回了 4xx** | 违背 `11-B` 的「统一 200 + 业务码」 | `ErrorCode` 里**默认 `httpStatus = 200`**；只有 4 个例外显式声明 |
| **R12** | **`countGroupedByIntentionIdIn` 返回值被当作「完整映射」** | 无流水的意向 `trade_count` 变成异常或 `null` | **缺失 = 0**（约束 C8）；加测试覆盖「0 次流水」的意向 |
| **R12b** | **重排队后把 `fail_type` 清成 `null`** | 违反 `DEC-DB-10` ①；「最后一条流水 ↔ 意向状态」一致性核对失败 | 重排队后 `fail_type` **保留 `requeued`**（见 §3.3.3 的说明） |
| **R13** | **测试库残留流水** | 反复跑测试后数据膨胀、断言污染 | 测试基类显式删除指向本测试意向的流水（交接说明 §10.4 第 1 条） |
| **R14** | **误引入 JSP 依赖 / 误建 JSP 目录** | 越出本轮范围 | §2.1 的「不新增依赖」清单；代码评审检查项 |
| **R15** | **`publishGoods` 的并发竞态** | 可能出现 2 件在售商品（`INV-01`） | **已接受风险**（`DEC-DB-06`）；保留前置校验 + 记录日志；若引入多管理员须重评 |
| **R16** | **口令码重试上限被穿透** | 极端情况下唯一索引冲突导致提交失败 | 生成时查重（≤5 次）+ **捕获 `DataIntegrityViolationException` 再重试一次**；仍失败则抛 `50000` |
| **R17** | **`token` 泄漏到日志** | 安全事件 | 不打印实体；`Intention.toString()` 已不含 `token`；日志评审检查项 |
| **R18** | **`.mvn/maven.config` 的相对路径** | 在别处执行 `mvn` 会另下一份依赖 | **统一在 `simple-shop-backend/` 目录执行 `mvn`**（交接说明 §2.1） |
| **R19** | **MySQL 容器未启动** | `Communications link failure` | `docker start <容器名>`；数据在容器卷里，重启不丢（交接说明 §2 第 6 项） |
| **R20** | **改动 `V1`/`V2` 迁移脚本** | Flyway 校验和失配，应用启动直接报错 | 本轮**不新增、不修改**任何迁移脚本 |

**自检用的一次性检查命令**（编码完成后跑一遍）：

```powershell
cd C:\workspace\simple-shop\simple-shop\simple-shop-backend

# R6：禁用本地时间 API（结果应为空或仅注释）
Get-ChildItem -Recurse -Filter *.java src\main | Select-String -Pattern 'LocalDateTime\.now\(|new Date\(|System\.currentTimeMillis\('

# R17：排查口令码被打印
Get-ChildItem -Recurse -Filter *.java src\main | Select-String -Pattern 'getToken\(\)' | Select-String -Pattern 'log\.|print|String\.format'

# R11：确认 ErrorCode 中的 httpStatus 默认值
Get-ChildItem -Recurse -Filter *.java src\main | Select-String -Pattern 'HttpStatus\.'

# R14：确认未引入 JSP 相关依赖
Select-String -Path pom.xml -Pattern 'jasper|jstl|thymeleaf|freemarker'
```
