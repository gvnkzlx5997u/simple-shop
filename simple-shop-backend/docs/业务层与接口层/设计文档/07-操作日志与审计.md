# 7. 操作日志与审计（`NFR-12`）

见 §3.3.8。补充落地细节：

- **logback-spring.xml** 新增：
  - `com.simpleshop.audit` logger → `logs/audit.log`；
  - `RollingFileAppender` + `SizeAndTimeBasedRollingPolicy`，`maxHistory="90"`（3 个月，`12-P7`）；
  - `pattern` 含 `%d{yyyy-MM-dd'T'HH:mm:ss.SSS'Z', UTC}`（**UTC**，不用本地时间）。
- **日志字段**：`operationType`（冻结/解冻/手动下架/进入交易/标记成功/标记失败-作废/标记失败-重排/查看口令码/修改密码）、`targetType`+`targetId`、`operator`（账号）。
- **禁令**：不记 `token`、不记密码、不记 `fail_reason` 全文（可选：记长度）。`Intention.toString()` 已刻意不含 `token`，但**Service 仍应避免整体打印实体**——推荐只打印 `id`。
