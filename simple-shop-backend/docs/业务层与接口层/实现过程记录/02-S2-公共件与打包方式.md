# 8.6 S2 完成记录（2026-10-10）

> **本步含一项计划外变更：打包方式 jar → war**（用户指示，为下一轮买家端 JSP 做准备）。该变更已回写 §2.1。

**A. 打包方式变更（jar → war）**

| 项 | 改动 | 理由 |
| --- | --- | --- |
| `pom.xml` | `<packaging>war</packaging>`；`<finalName>simple-shop</finalName>`（产物 `target/simple-shop.war`） | **下一轮买家端为服务端渲染的 JSP**（`C-05`、`A-02`、`A-05`）。JSP 由 servlet 容器编译，需要 `WEB-INF` 下的 web 资源结构，**jar 无法承载**。本轮先改打包方式，下一轮只需加 `tomcat-embed-jasper` 依赖 + `src/main/webapp/WEB-INF/views` 目录 |
| `SimpleShopApplication` | 改为 `extends SpringBootServletInitializer`，并实现 `configure(SpringApplicationBuilder)` | 同时支持**两种启动方式**：① `java -jar target/simple-shop.war`（开发期，走 `main`，启 embedded Tomcat）；② 放进外部 Tomcat 的 `webapps/`（走 `configure`）。两条路径配置同源，行为一致 |

**⚠️ 本轮【有意保留】embedded Tomcat**（即 `spring-boot-starter-web` 的默认传递依赖，**未**设为 `provided`）：
- **为什么**：否则 `java -jar` 会因缺少 servlet 容器**无法启动**，开发与自测将失去最方便的验证手段（本步的验证正是走这条路）。
- **代价**：war 里同时含 embedded Tomcat 与 `WEB-INF/lib-provided`，部署到外部容器时容器自带 Tomcat 会优先，属可接受的冗余（体积约 56MB，其中大部分是依赖）。
- **何时收紧**：若**确定不再需要 `java -jar`**，再把 embedded Tomcat 改为 `provided` 并同时加 `jakarta.servlet-api`(provided)。JSP 直出所需的 `tomcat-embed-jasper` 属下一轮依赖，**本轮不加**。

**D. S2 期间发现并处理的三件事**

1. **`session.purge-interval` 配置项做不成**：`@Scheduled(fixedDelay = ...)` 要求**编译期常量**，用配置值必须引入 `SchedulingConfigurer` 手工注册任务——为一个 60 秒的清理节奏加一个配置类，**属过度设计**。因此**移除该配置项**，在 `SessionStore.PURGE_INTERVAL_MS` 固定 60 秒并注明理由。同时把配置键由 `timeout-minutes` 改为 Duration 简写 `timeout: 30m` / `timeout-tolerance: 60s`。
2. **`logback` 的 `${VAR:-default}` 对环境变量不可靠**：logback 手册只保证「系统属性 / 已定义属性」的默认值语义，因此审计日志目录改用**系统属性** `-DAUDIT_LOG_PATH=...` 覆盖，并在配置里注明。
3. **`I11-01` 与 `I11-02` 共用路径 `/api/seller/session`**（一个 `POST`、一个 `DELETE`），而 `excludePathPatterns` 只能按**路径**排除 ⇒ **退出登录也不被拦截器校验**。经评估这是**安全且可接受**的：`I11-02` 的语义是「解析并移除 token」，`SessionStore.remove` 对无效 token 是**幂等无操作**、不泄漏任何信息，且契约对 `I11-02` 列出的错误码本来只有 `10002`（幂等成功同样可接受）。该取舍已写入 `WebMvcConfig` 的注释；若将来要严格校验，需改为按「路径 + 方法」精确排除。

> **⚠️ 一处口径需在 S3 落实**：`I11-02`（退出登录）的 Controller 必须**自己**处理「无/无效 token」的情形（不能依赖拦截器），并保证**不抛 401**（否则与「幂等退出」的取舍不一致）。这一点已记入上表第 3 条。
